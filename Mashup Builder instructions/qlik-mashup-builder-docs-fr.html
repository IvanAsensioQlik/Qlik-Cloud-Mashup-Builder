Documentation de référence

Qlik Mashup Builder

Un outil visuel pour concevoir un mashup mobile basé sur l'API Qlik Embed, sans écrire de code : tu configures l'en-tête, crées des onglets d'accueil et d'analyse, places des objets Qlik dans des lignes, et exportes un index.html prêt à déployer (et, si besoin, un oauth-callback.html).

Ce guide explique, bloc par bloc, ce que signifie chaque option du panneau de configuration et quel effet elle a sur le mashup exporté.

1App et Authentification

Définit comment le mashup exporté se connecte à ton environnement Qlik Cloud. Se configure une seule fois et s'applique à tous les onglets, sauf si un onglet précis indique son propre App ID.

App ID (par défaut) global
Identifiant de l'app Qlik utilisé par tous les objets du mashup, sauf si un onglet analytique active l'option « Utiliser un ID d'application différent de celui global ».
Type d'authentification
Anonyme : accès sans connexion utilisateur, pensé pour du contenu public ou de démonstration.
OAuth2 : l'utilisateur s'authentifie avec ses identifiants Qlik Cloud ; nécessite une URL de redirection et génère un second fichier de callback (voir ci-dessous).
data-host
URL du tenant Qlik Cloud (par exemple, https://monentreprise.eu.qlikcloud.com). Injectée dans le script d'authentification de l'index.html.
data-client-id
Identifiant du client OAuth2/API enregistré dans Qlik Cloud pour cette intégration.
data-access-code Anonyme uniquement
Code d'accès qui permet l'affichage anonyme de l'app.
data-redirect-uri OAuth2 uniquement
URL vers laquelle Qlik redirige après la connexion — généralement l'endroit où tu publies oauth-callback.html.
Générer oauth-callback.html
Interrupteur visible uniquement avec l'authentification OAuth2. S'il est activé, cliquer sur « Exporter » inclut aussi le fichier oauth-callback.html, nécessaire pour compléter le flux de connexion.
Comme les navigateurs bloquent un second téléchargement automatique, les deux fichiers sont livrés ensemble dans un seul mashup-export.zip (index.html + oauth-callback.html).

2En-tête

L'en-tête est la bande supérieure fixe du mashup — logo, filtres, informations — ainsi que le système de navigation entre les onglets. Ses réglages sont globaux : ils s'appliquent de la même façon à tous les onglets.

Navigation générale

Comment l'utilisateur se déplace entre les onglets.

Navigation en pied de page
Barre fixe en bas de l'écran avec un bouton par onglet (icône + nom). L'icône de l'onglet actif est mise en valeur avec la « Couleur des icônes de navigation ».
Panneau supérieur masqué
Au lieu d'un pied de page fixe, une icône de menu (☰) apparaît en haut à gauche, avant le logo. En la touchant, un panneau latéral sombre listant tous les onglets s'ouvre.
Police générale
Typographie utilisée dans tout le mashup exporté (Inter, Système, Georgia, Monospace, Poppins ou Playfair Display).
Taille minimale du texte
Aucun texte du mashup n'est jamais affiché en dessous de cette taille, même si le design original prévoyait plus petit. Protège la lisibilité sur les petits écrans. Valeur par défaut : 15px.

Logo et marque

Position du logo
Gauche, centre ou droite dans la barre supérieure.
Logo
Image (URL ou fichier importé) affichée près du texte avant/après.
Image supplémentaire dans l'en-tête
Une seconde petite icône/image placée du côté opposé au logo.
Texte avant le logo / Texte après le logo
Libellés de texte de chaque côté de l'image du logo (par exemple, le nom de l'entreprise).

Couleurs de l'en-tête

Il existe deux niveaux de couleur indépendants : la barre supérieure globale, et la couleur des icônes de navigation (pied de page ou menu).

Couleur de fond de la barre supérieure
Fond de la bande fixe où se trouvent le logo, l'icône de filtres et l'icône d'information.
Couleur du texte et des icônes de la barre supérieure
S'applique au texte du logo et, par héritage, à toutes les icônes de cette barre (menu, filtre, information).
Couleur des icônes de navigation
Couleur de l'icône (et du texte, dans le pied de page) de l'onglet actif, dans la navigation en pied de page ou dans le menu latéral.
Couleur de l'icône active
Couleur de fond derrière l'icône de l'onglet actif dans le panneau du menu latéral (l'icône elle-même est dessinée par-dessus ce fond), afin de garantir un contraste suffisant face aux icônes inactives.
Couleur de fond par défaut des objets
Couleur que recevront automatiquement les objets Qlik créés à partir de maintenant (dans n'importe quel onglet analytique). Chaque objet peut ensuite la modifier individuellement.

Panneau de filtres global

Un panneau de filtres unique, partagé par tous les onglets analytiques (n'apparaît jamais sur Home).

Icône du panneau de filtres
Active l'icône de filtre dans l'en-tête. En la touchant, un tiroir latéral droit s'ouvre avec l'objet de sélections Qlik.
ID de l'objet de sélections
Object ID Qlik affiché dans le panneau de filtres (type analytics/chart).
Largeur du panneau de filtres
Largeur du tiroir de filtres, en pixels. Plage autorisée : 200–500px, valeur par défaut 290px.
Boutons du panneau de filtres (jusqu'à 3)
Object ID optionnels de boutons Qlik qui apparaissent directement dans l'en-tête, à gauche de l'icône de filtres (pas dans le tiroir), à la même taille que cette icône.

Titre, favicon et CSS externe

Titre de la page (<title>)
Texte affiché dans l'onglet du navigateur et dans les favoris. S'il est laissé vide, l'export utilise « Qlik Mashup » par défaut.
Favicon (URL)
S'il est rempli, ajoute un <link rel="shortcut icon"> dans l'index.html pointant vers cette URL.
Importer un CSS externe (URL)
Ajoute une feuille de style supplémentaire au <head> de l'export, via un <link rel="stylesheet">, pour surcharger ou étendre les styles.

3Création des onglets

Un mashup se compose de deux types d'onglets : Home (accueil) et Analytics (contenu analytique). Chaque onglet est indépendant et possède son propre panneau de configuration.

Concepts communs à tout onglet

Icône d'information
Active une icône « i » dans l'en-tête pour cet onglet. En la touchant, affiche une fenêtre « À propos de cette application » avec le texte que tu écris. Les URL et adresses e-mail présentes dans ce texte sont détectées et colorées automatiquement ; les retours à la ligne sont conservés comme des paragraphes distincts.
Icône de cet onglet dans le pied de page / menu
Icône (parmi un catalogue de 15) représentant l'onglet dans la navigation en pied de page ou dans le menu latéral.
Palette de cet onglet
Applique l'une des 7 combinaisons de couleurs prédéfinies (voir section 4) à tout l'onglet : fond, cartes, bordures et accents.

Onglet Home (accueil)

Premier écran du mashup : une image ou vidéo d'en-tête avec un titre, et des accès rapides vers les autres onglets.

Couleur de fond
Couleur de fond propre à cet onglet, indépendante du reste.
Type de média / URL
Image ou vidéo de fond dans la zone supérieure (« hero »). La vidéo est centrée et recadrée pour remplir l'espace sans recouvrir l'en-tête.
Hauteur du bloc
Pourcentage de l'écran occupé par l'image/vidéo d'en-tête.
Titre / Sous-titre
Textes principaux superposés sur l'image d'en-tête.
Position du texte
Emplacement du bloc titre+sous-titre sur l'image : en haut, au centre ou en bas, aligné à gauche ou centré.
Texte supplémentaire (facultatif) + couleur
Un bloc de texte additionnel (par exemple, une légende descriptive), avec sa propre couleur configurable.
Afficher le texte supplémentaire sur la photo
Interrupteur : s'il est activé, le texte supplémentaire apparaît dans l'en-tête/la photo (à côté du titre) ; sinon, il apparaît en dessous, hors de l'image.
Cartes numérotées d'accès aux onglets
Liste de cartes (01, 02, 03…) renvoyant directement vers chacun des autres onglets du mashup.
Icône pour aller à l'onglet suivant
Flèche sur l'image d'en-tête qui navigue vers l'onglet suivant.
Inclure un pied de page sur cet onglet + texte
Ajoute une bande de texte à la fin de l'écran d'accueil. Utilise la même couleur de fond et de texte que celles configurées pour la barre supérieure globale, et s'affiche toujours en 13px.

Onglets Analytics

Onglets de contenu : titre propre, navigation entre onglets, et une ou plusieurs lignes d'objets Qlik.

Couleur de fond de l'onglet
Fond de tout l'onglet, y compris la bande titre/flèches située juste sous l'en-tête globale (cette bande n'a pas de couleur propre : elle adopte toujours celle de l'onglet).
Sous-titre
Ligne secondaire, en gris clair et caractère plus petit, sous le nom de l'onglet.
Utiliser un ID d'application différent de celui global
Permet à cet onglet précis d'utiliser une app Qlik différente de celle configurée dans « App et Authentification ».
Icône pour aller à l'onglet précédent / suivant
Les flèches < > près du titre, pour se déplacer entre les onglets dans l'ordre.
Couleur du titre et des flèches de navigation
Une seule couleur partagée par le nom de l'onglet et par les flèches < >.
Espacement entre les lignes
Espace vertical, en pixels, entre les différentes lignes d'objets de cet onglet. Plage : 5–30px, par défaut 15px.

Lignes et objets

Le contenu d'un onglet Analytics est organisé en lignes ; chaque ligne contient un ou plusieurs objets Qlik.

Ligne

Occuper % de l'écran
Si activé, la ligne occupe le pourcentage indiqué de l'écran disponible (sans compter l'en-tête, le pied de page ni les flèches de navigation).
Hauteur minimale (px)
Un plancher de hauteur que la ligne respecte toujours, qu'elle utilise un pourcentage d'écran ou qu'elle grandisse selon son contenu.
Largeur des objets
Non configurable manuellement : les objets d'une même ligne se partagent toujours la largeur à parts égales, et restent côte à côte sur la même ligne (s'ils ne rentrent pas, ils passent à la ligne suivante).

Objet

Object ID (Qlik)
Identifiant de l'objet Qlik Sense intégré via qlik-embed.
C'est une carte ou une extension
Change le type d'intégration de analytics/chart à classic/chart, nécessaire pour les cartes et extensions personnalisées.
Avec bordure + couleur de la bordure
Ajoute une bordure de 1px autour de l'objet (ou une bande colorée à gauche, si réduit).
Ombre douce
Ajoute une ombre légère autour de l'objet. Désactivée par défaut.
Couleur de fond de l'objet
Couleur de fond de la carte qui contient l'objet (ou du menu, si réduit). Une fois développé en plein écran, l'objet utilise le design défini dans Qlik, sans cette couleur de fond.
Extensible en plein écran
Affiche une icône d'extension sur l'objet ; en la touchant, il occupe tout l'écran sauf l'en-tête avec le logo.
Réduit par défaut
L'objet est affiché comme une carte compacte (titre + description + flèche), au lieu d'un graphique. Il n'a que deux états possibles : réduit ou développé en plein écran (il n'existe pas d'état intermédiaire, et la hauteur minimale de la ligne est ignorée). Il occupe toujours 100 % de la largeur, même s'il partage une ligne avec d'autres objets.
Titre / Description (réduit)
Textes de la carte compacte. La description ne dépasse jamais 14px, même si la taille minimale de texte globale est plus grande.
Couleur de la police (réduit)
Couleur du titre et de la description de la carte compacte — utile quand la couleur de fond choisie ne contraste pas bien avec la couleur de texte du thème.

4Palettes de couleurs

Sept combinaisons de couleurs prédéfinies, applicables globalement (pour les nouveaux onglets) ou individuellement, par onglet.

Qlik Clásico — fond blanc, texte sombre, accent vert Qlik. Préréglage par défaut.
Editorial Oscuro — fond quasi noir, accent rouge.
Tech Neón — fond noir pur, accent vert néon.
Cálido Editorial — fond crème, accent ambre.
Claro Minimal — fond clair, détails sombres.
Oscuro Ámbar — fond sombre, accent jaune/ambre.
Azul Metálico — fond bleu foncé métallique, détail clair.

6Enregistrer et charger des projets

Le travail en cours n'est jamais perdu, et peut aussi être archivé ou partagé comme un fichier indépendant.

Enregistrement automatique
Chaque modification est enregistrée, silencieusement, dans le navigateur. Si tu recharges la page par accident, le projet se restaure seul (un bref message le confirme).
Enregistrer le projet (.json)
Télécharge un fichier .json sous le nom que tu écris, avec la configuration complète : en-tête, onglets, lignes, objets, palettes et langue.
Charger le projet (.json)
Lit un .json enregistré précédemment et reconstruit le projet exactement comme il était. Utile comme point de contrôle nommé, comme sauvegarde, ou pour continuer le travail dans un autre navigateur.

7Export

Le bouton « Exporter » génère le mashup final, prêt à être mis en ligne sur un serveur web ou un bucket (comme le S3 utilisé dans les exemples de cette documentation).

index.html
Page unique et autonome avec l'en-tête, tous les onglets, les scripts d'authentification Qlik Embed et la navigation entre les écrans.
oauth-callback.html
Généré uniquement avec l'authentification OAuth2 et l'interrupteur « Générer oauth-callback.html » activé. Livré avec l'index.html à l'intérieur de mashup-export.zip.
