Qlik Mashup Builder

A visual tool for designing a mobile mashup built on the Qlik Embed API, with no code required: configure the header, create welcome and analytics tabs, lay out Qlik objects in rows, and export a ready-to-deploy index.html (plus, when needed, an oauth-callback.html).

This guide explains, block by block, what each option in the configuration panel means and how it affects the exported mashup.

1App & Authentication

Defines how the exported mashup connects to your Qlik Cloud environment. It's configured once and applies to every tab, unless a specific tab sets its own App ID.

App ID (default) global
The Qlik app used by every object in the mashup, unless an analytics tab turns on "Use a different App ID than the global one".
Authentication type
Anonymous: access with no user login, meant for public or demo content.
OAuth2: the user signs in with their Qlik Cloud credentials; requires a redirect URL and generates a second callback file (see below).
data-host
URL of the Qlik Cloud tenant (for example, https://mycompany.eu.qlikcloud.com). Injected into the authentication script of index.html.
data-client-id
OAuth2/API client identifier registered in Qlik Cloud for this integration.
data-access-code Anonymous only
Access code that enables anonymous viewing of the app.
data-redirect-uri OAuth2 only
The URL Qlik redirects to after login — normally wherever you publish oauth-callback.html.
Generate oauth-callback.html
Switch visible only with OAuth2 authentication. When on, clicking "Export" also includes the oauth-callback.html file, required to complete the login flow.
Because browsers block a second automatic download, both files are delivered together inside a single mashup-export.zip (index.html + oauth-callback.html).

2Header

The header is the fixed top strip of the mashup — logo, filters, information — plus the system used to navigate between tabs. Its settings are global: they apply the same way to every tab.

General navigation

How the user moves between tabs.

Bottom navigation
Fixed bar at the bottom with one button per tab (icon + name). The active tab's icon is highlighted using the "Navigation icons color".
Hidden top panel
Instead of a fixed footer, a menu icon (☰) appears top-left, before the logo. Tapping it opens a dark side panel listing every tab.
General font
Typeface used throughout the exported mashup (Inter, System, Georgia, Monospace, Poppins or Playfair Display).
Minimum text size
No text in the mashup ever renders below this size, even if the original design called for something smaller. Protects legibility on small screens. Default: 15px.

Logo & branding

Logo position
Left, center or right within the top bar.
Logo
Image (URL or uploaded file) shown next to the before/after text.
Additional header image
A second small icon/image placed on the side opposite the logo.
Text before logo / Text after logo
Text labels on either side of the logo image (for example, the company name).

Header colors

There are two independent color levels: the global top bar, and the color of the navigation icons (footer or menu).

Top bar background color
Background of the fixed strip that holds the logo, the filter icon and the info icon.
Top bar text & icon color
Applied to the logo text and, by inheritance, to every icon in that bar (menu, filter, info).
Navigation icons color
Color of the active tab's icon (and its text, in the footer) within the bottom navigation or the side menu.
Active icon color
Background color behind the active tab's icon inside the side menu panel (the icon itself is drawn on top of it), to guarantee enough contrast against the inactive icons.
Default background color for objects
Color automatically applied to any Qlik object you create from now on (in any analytics tab). Each object can still override it individually afterwards.

Global filter panel

A single filter panel, shared by every analytics tab (it never appears on Home).

Filter panel icon
Turns on the filter icon in the header. Tapping it opens a right-hand drawer with the Qlik selections object.
Selections object ID
Qlik Object ID displayed inside the filter panel (type analytics/chart).
Filter panel width
Width of the filter drawer, in pixels. Allowed range: 200–500px, default 290px.
Filter panel buttons (up to 3)
Optional Qlik button object IDs shown right in the header, to the left of the filter icon (not inside the drawer), at the same size as that icon.

Title, favicon & external CSS

Page title (<title>)
Text shown in the browser tab and in bookmarks. If left blank, the export defaults to "Qlik Mashup".
Favicon (URL)
When filled in, adds a <link rel="shortcut icon"> to index.html pointing at that URL.
Import external CSS (URL)
Adds an extra stylesheet to the export's <head> via a <link rel="stylesheet">, to override or extend styles.

3Building tabs

A mashup is made up of two kinds of tabs: Home (welcome) and Analytics (analytical content). Each tab is independent and has its own configuration panel.

Concepts common to every tab

Information icon
Turns on an "i" icon in the header for this tab. Tapping it shows an "About this app" popup with the text you write. URLs and email addresses inside that text are detected and colored automatically; line breaks are kept as separate paragraphs.
This tab's icon in the footer / menu
Icon (chosen from a catalog of 15) representing the tab in the bottom navigation or the side menu.
This tab's palette
Applies one of the 7 color presets (see section 4) to the whole tab: background, cards, borders and accents.

Home tab (welcome)

The mashup's first screen: a header image or video with a title, plus quick links to the other tabs.

Background color
This tab's own background color, independent from the rest.
Media type / URL
Background image or video in the top ("hero") area. Video is centered and cropped to fill the space without covering the header.
Block height
Percentage of the screen taken up by the header image/video.
Title / Subtitle
Main text overlaid on the header image.
Text position
Where the title+subtitle block sits over the image: top, center or bottom, left-aligned or centered.
Extra text (optional) + color
An additional text block (for example, a descriptive caption), with its own configurable color.
Show extra text over the photo
Switch: when on, the extra text appears inside the header/photo (next to the title); when off, it appears below, outside the image.
Numbered shortcut cards to tabs
A list of cards (01, 02, 03…) linking directly to each of the mashup's other tabs.
Icon to go to the next tab
Arrow over the header image that navigates to the next tab.
Include a footer on this tab + text
Adds a text strip at the bottom of the welcome screen. It uses the same background and text color configured for the global top bar, and is always shown at 13px.

Analytics tabs

Content tabs: their own title, navigation between tabs, and one or more rows of Qlik objects.

Tab background color
Background of the whole tab, including the title/arrows strip right below the global header (that strip has no color of its own: it always takes the tab's color).
Subtitle
Secondary line, in light gray and a smaller size, under the tab's name.
Use a different App ID than the global one
Lets this specific tab use a Qlik app different from the one set in "App & Authentication".
Icon to go to previous / next tab
The < > arrows next to the title, for moving between tabs in order.
Title & navigation arrows color
A single color shared by the tab's name and by the < > arrows.
Spacing between rows
Vertical space, in pixels, between this tab's rows of objects. Range: 5–30px, default 15px.

Rows & objects

An Analytics tab's content is organized into rows; each row holds one or more Qlik objects.

Row

Use % of the screen
When on, the row takes up the given percentage of the available screen (not counting the header, footer or navigation arrows).
Minimum height (px)
A height floor the row always respects, whether it's using a screen percentage or growing to fit its content.
Object width
Not manually configurable: objects in the same row always split the width equally, and stay side by side on the same line (if they don't fit, they wrap to the next line).

Object

Object ID (Qlik)
Identifier of the Qlik Sense object embedded via qlik-embed.
Is a map or extension
Switches the embed type from analytics/chart to classic/chart, required for maps and custom extensions.
With border + border color
Adds a 1px border around the object (or a colored stripe on the left, if minimized).
Soft shadow
Adds a light shadow around the object. Off by default.
Object background color
Background color of the card holding the object (or of the menu, if minimized). Once expanded to full screen, the object uses the design defined in Qlik, without this background color.
Expandable to full screen
Shows an expand icon over the object; tapping it makes it fill the whole screen except the header with the logo.
Minimized by default
The object is shown as a compact card (title + description + arrow), instead of as a chart. It only has two possible states: minimized or expanded to full screen (there is no in-between state, and it ignores the row's minimum height). It always takes 100% of the width, even if it shares a row with other objects.
Title / Description (minimized)
Text shown on the compact card. The description never exceeds 14px, even if the global minimum text size is larger.
Font color (minimized)
Color of the title and description on the compact card — useful when the chosen background color doesn't contrast well with the theme's text color.

4Color palettes

Seven predefined color combinations, applicable globally (for new tabs) or individually, per tab.

Qlik Clásico — white background, dark text, Qlik green accent. Default preset.
Editorial Oscuro — near-black background, red accent.
Tech Neón — pure black background, neon green accent.
Cálido Editorial — cream background, amber accent.
Claro Minimal — light background, dark details.
Oscuro Ámbar — dark background, yellow/amber accent.
Azul Metálico — dark metallic blue background, light detail.

6Saving & loading projects

Work in progress is never lost, and can also be archived or shared as a standalone file.

Autosave
Every change is saved silently in the browser. If you accidentally reload the page, the project restores itself (you'll see a brief notice confirming it).
Save project (.json)
Downloads a .json file, under whatever name you type, with the full configuration: header, tabs, rows, objects, palettes and language.
Load project (.json)
Reads a previously saved .json file and rebuilds the project exactly as it was. Useful as a named checkpoint, as a backup, or to carry on the work in a different browser.

7Export

The "Export" button generates the final mashup, ready to upload to a web server or bucket (such as the S3 used in this documentation's examples).

index.html
A single, self-contained page with the header, every tab, the Qlik Embed authentication scripts, and navigation between screens.
oauth-callback.html
Generated only with OAuth2 authentication and the "Generate oauth-callback.html" switch on. Delivered together with index.html inside mashup-export.zip.
