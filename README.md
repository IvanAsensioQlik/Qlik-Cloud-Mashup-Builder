# Qlik-Cloud-Mashup-Builder
Artifact format JSX to deploy mashups for Qlik Cloud using the latest API Qlik Embed. That's a no-code aproach. Contains documentation to start and configure everything,

Author: Ivan Felipe ivan.felipe@qlik.com
Updated: 5th Oct 2'26

Enable beautiful mashups without the need of skills in HTML or JS.
